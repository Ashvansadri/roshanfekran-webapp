# روشنفکران | Roshanfekran Academy

سامانه جدید روشنفکران — مهاجرت تدریجی از Floot به GitHub + Render + Supabase.

## Live staging
https://roshanfekran-next-academy.onrender.com

این نسخه برای بررسی و آزمایش است و هنوز جایگزین تمام بخش‌های عملیاتی سایت Floot نیست.

## معماری
- site/: صفحه‌های عمومی، پنل نقش‌محور، CSS فارسی و افکت WebGL با حالت جایگزین CSS.
- Supabase: دیتابیس و احراز هویت اصلی؛ هیچ کپی موازی از اطلاعات کاربران ساخته نمی‌شود.
- Render: static site با انتشار خودکار از branch جداگانه roshanfekran-next-20261021.
- scripts/verify.mjs: بررسی کد، اتصال فایل‌ها، نبود کلید حساس و مرورگر فارسی.

## امکانات پیاده‌سازی‌شده در staging
- صفحه عمومی و کاتالوگ واقعی دوره‌های دارای ثبت‌نام باز، اخبار و نکته روز.
- پیش‌ثبت‌نام دوره با رسید و کد رهگیری از Supabase فعلی (نه پرداخت آنلاین خودکار).
- ورود بر اساس نقش سرور؛ پروفایل هنرجو، نمونه‌کار، آزمون، مأموریت و رزومه چاپی.
- والدین: فرزندان مجاز، رضایت/لغو انتشار و چرخه ۳۰ درس خانواده.
- مدیر: نمای دوره‌ها، فعال‌سازی مأموریت‌های ۹۰روزه و صدور دعوت امن.
- صفحه عمومی رزومه فقط با توکن معتبر و رضایت لازم.
- PWA نصب‌پذیر؛ فعلاً اعلان Push و دستیار مولد AI متصل و آزمون‌شده نیستند.

## مسیرهای باقی‌مانده تا تحویل نهایی
- تست کامل مرورگر، موبایل و ورود حساب‌های واقعی مجاز، و آزمون منفی تفکیک اطلاعات.
- انتقال جامع مدیریت مالی، قراردادها، اقساط و ارزیابی مدرس؛ اکنون بخشی به Floot قدیمی لینک دارد.
- بررسی سرویس پیامک، درگاه پرداخت رسمی، Web Push با رضایت و AI پاسخ‌گو و سهمیه سروری.
- آزمون ثبت‌نام/رسید و ابطال فوری لینک رزومه در شرایط عملیاتی امن.
- بررسی تغییر دامنه نهایی فقط پس از موفقیت QA و مجوز مدیر.

## احتیاط امنیتی
مخزن عمومی است: هیچ داده هنرجو، کلید service_role یا اسرار حساب‌ها در آن قرار ندهید. ورود و دسترسی‌ها توسط Supabase RPC و RLS کنترل می‌شوند.

## روش rollback
Render به‌صورت خودکار آخرین commit شاخه staging را منتشر می‌کند. بازگشت frontend با برگرداندن commit شاخه و انتشار دوباره است؛ این کار تغییرات دیتابیس Supabase را برنمی‌گرداند. هر مهاجرت باید راه برگشت مستقل داشته باشد.
