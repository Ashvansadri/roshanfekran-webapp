# Student Profile Demo Plan

## Goal
Create a visible demo version of the Academy Control Center before connecting real deployment.

## Student Profile View
- Personal information
- Enrollments
- Course history
- Tuition summary
- Discount history
- Payments
- Installments
- Outstanding balance
- Activity log

## Demo Data
- 20 sample students
- Multiple courses
- Paid, partial, and overdue accounts
- Completed and active enrollments

## Acceptance Checks
- Balance calculation is consistent
- Payment history is traceable
- Installment status is visible
- No real student data is used

## Next Implementation Order
1. Student detail UI
2. Payment actions
3. Installment actions
4. Dashboard financial widgets
5. Deployment preparation
