# Financial Engine v0.2

## هدف
ساخت هسته مالی آموزشگاه برای کنترل دقیق شهریه، اقساط، پرداخت و مطالبات.

## قواعد اصلی

### Enrollment
- هر ثبت‌نام دارای شهریه اولیه، تخفیف، مبلغ نهایی و وضعیت مالی است.
- مبلغ نهایی = شهریه - تخفیف.

### Payment
- هر پرداخت دارای:
  - مبلغ
  - تاریخ
  - روش پرداخت
  - ثبت‌کننده
  - مرجع/توضیح
- پرداخت بیشتر از مانده مجاز نیست.

### Installment
- هر قسط دارای:
  - مبلغ
  - تاریخ سررسید
  - وضعیت پرداخت
  - مبلغ باقی‌مانده

## گزارش‌ها

- درآمد روزانه
- درآمد ماهانه
- مطالبات کل
- اقساط سررسید گذشته
- هنرجویان تسویه‌شده
- هنرجویان بدهکار

## کنترل کیفیت

قبل از استفاده واقعی:
- تست پرداخت کامل
- تست پرداخت چندمرحله‌ای
- تست تخفیف
- تست برگشت/اصلاح با Audit Log
- تست دسترسی نقش‌ها

## مرحله بعد
پیاده‌سازی APIهای مالی و اتصال UI پرونده هنرجو به تراکنش‌ها.
