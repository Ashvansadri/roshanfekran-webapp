# Academy Control Center v0.2 — Student Profile Module

## Goal
Convert the simple student list into a complete operational student پرونده.

## Student Profile Sections

### 1. Identity
- Full name
- Mobile
- National ID
- City
- Registration date
- Notes

### 2. Education Status
- Current status
- Registered courses
- Class/group
- Instructor
- Start and end dates

### 3. Financial Overview
- Total contract value
- Discount
- Final payable amount
- Paid amount
- Remaining balance
- Payment status

### 4. Installments
Each installment must include:
- Amount
- Due date
- Status (pending/paid/overdue)
- Payment history

### 5. Payment Timeline
Immutable financial history:
- Payment date
- Amount
- Method
- Operator
- Reference/receipt number

### 6. Audit
Every sensitive action must record:
- Actor
- Time
- Action
- Before/after values

## Acceptance Criteria
- No financial data is deleted.
- Remaining balance is calculated automatically.
- Student history is visible from one page.
- Permissions are checked before financial actions.
