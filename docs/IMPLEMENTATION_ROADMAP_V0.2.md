# Academy Control Center v0.2 Roadmap

## Goal
Turn the MVP into a practical daily operation system for Roshanfekran Academy.

## Module 1 - Student File
- Complete student profile
- Contact information
- Enrollment history
- Financial summary
- Payment timeline
- Notes and audit history

## Module 2 - Enrollment Flow
- Lead -> consultation -> pre-registration -> active student
- Course selection
- Discount handling
- Final tuition calculation
- Enrollment confirmation

## Module 3 - Finance
- Payment receipt records
- Payment methods
- Installment plans
- Outstanding balance dashboard
- Monthly revenue reports
- CSV export

## Module 4 - Operations
- Classes
- Instructors
- Attendance foundation
- Course capacity

## Module 5 - Security
- Role based access
- Admin actions audit
- Production environment restrictions

## Deployment gate
Before production:
1. Deploy staging environment
2. Run financial test scenarios
3. Verify permissions
4. Backup strategy
5. Production migration plan
