# Academy Control Center Demo Scenarios

## هدف
داده‌های ساختگی برای تست قبل از اتصال به اطلاعات واقعی آموزشگاه.

## سناریوها

### 1. ثبت‌نام کامل
- هنرجو: علی رضایی
- دوره: هوش مصنوعی
- شهریه: 15000000
- پرداخت: 5000000
- مانده: 10000000

### 2. پرداخت اقساطی
- دو قسط ایجاد شود
- قسط اول پرداخت شده
- قسط دوم سررسید آینده داشته باشد

### 3. بدهکار
- هنرجو دارای مانده مثبت باشد
- در داشبورد در بخش مطالبات نمایش داده شود

### 4. تسویه کامل
- مجموع پرداخت‌ها برابر شهریه نهایی باشد
- وضعیت مالی تسویه شده نمایش داده شود

### معیار پذیرش
- هیچ داده واقعی استفاده نشود
- محاسبه مانده دستی نباشد
- همه تغییرات مالی قابل ثبت در تاریخچه باشند
